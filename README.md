# BSCS26111 — ICT Web Development Projects (Lab 05)

A multi-part web application developed to demonstrate core front-end skills using **HTML5**, **CSS3**, and **JavaScript (DOM Manipulation)**.

---

## Project Overview

1. **Prism Tech Hardware Showcase**  
   A multi-page responsive web catalog featuring high-performance graphics hardware (NVIDIA & AMD GPU lineups).
2. **Interactive Dummy Chatbot**  
   A standalone chat client interface utilizing JavaScript event handling and dynamic DOM manipulation.

---

## Features & Functionality

### 1. Prism Tech Product Website
- **Multi-Page Structure:** Dedicated navigation across `Home`, `Products`, and `About Us` pages.
- **Onload Event Handlers:** Utilizes `window.onload` to trigger a visitor welcome alert and dynamically render the current year in the footer via the `Date()` object.
- **Dynamic Stock Verification:** Individual interactive buttons that execute JavaScript functions (`checkStock()`) to update item availability status in the DOM.
- **Interactive Forms:** Contact page structured with HTML5 input validation and social links.

### 2. Interactive Dummy Chatbot
- **Dynamic DOM Rendering:** Instantiates distinct user and bot message bubbles dynamically upon sending.
